# 大明王朝 1566 · 剧情闯关

一个纯前端单文件的剧情闯关小游戏，灵感来自电视剧《大明王朝 1566》。

## 玩法

- **五大阵营**：皇帝·嘉靖 / 孤臣·海瑞 / 严党·严阁老 / 清流·徐阁老 / 司礼监·吕芳
- **每阵营 4 关**，共 20 段剧情：改稻为桑、赈粮案、青词宰相、治安疏、倒严之夜……
- 逐句演出 + 关键抉择：每个选择都会暗中改变钱粮、民力、圣眷、危机等局势数值
- 危机或罪证爆表立即败亡；走完全部剧情后按局势结算成败
- 通关进度保存在浏览器本地（localStorage）

## 在线游玩

直接用浏览器打开 `index.html` 即可，无需服务器、无任何依赖。

> 仅供娱乐，剧情演绎与史实、电视剧均有出入。
